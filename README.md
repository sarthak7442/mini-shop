# 🛍️ Mini Shop (Online Shopping Project)

A beginner-friendly online shopping page built with only **HTML, CSS and JavaScript**. No installs, no frameworks.

## How to run
1. Keep all files together in the `shop-app` folder.
2. Double-click `index.html` to open it in your browser. Done!

## What each file does
| File | Job |
|------|-----|
| `index.html` | The structure (header, products area, cart area) |
| `style.css` | The looks (colors, grid layout, mobile friendly) |
| `script.js` | The behavior (products, add to cart, quantity, total) |

## Features
- Product cards with name, price and an Add to Cart button
- Cart with + / − quantity buttons
- Live total price and cart item count
- Clear Cart button
- Cart is saved in your browser, so it stays after refresh
- Works on phones too

## Concepts you'll learn
- HTML: page structure
- CSS: flexbox, grid, hover effects, media queries
- JS: arrays, objects, functions, events, DOM, `localStorage`

## Try these challenges
1. Add a new product in the `products` list in `script.js`.
2. Change the currency symbol or the colors.
3. Add a search box that filters products by name.
4. Add a "Checkout" button that shows a thank-you message.
5. Add product categories (clothes, gadgets, etc.).
